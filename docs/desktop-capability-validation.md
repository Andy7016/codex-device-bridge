# 桌面接口验证清单

状态：2026-10-28 已完成只读探测与两条授权测试会话的真实写入/审批。详见[初次探测](results/2026-10-28-desktop-probe.md)和[原运行时控制结果](results/2026-10-28-desktop-runtime-control.md)。内部入口的版本约束与 ChatGPT 常驻上下文前提仍需解决。

## 目标

确定能否操作 Windows 桌面应用当前持有的同一条 Codex / ChatGPT 会话，并区分公开受支持接口与固定版本内部实现。版本、配置、身份和会话来源影响结果，必须记录。

## 准备与保护

- 只读记录桌面、CLI 和协议版本、接口来源及可用传输；不采集账户令牌、真实正文或全量数据库。
- 在桌面创建专用测试项目和两条含合成内容的会话，分别选择 Codex 与 ChatGPT；原始个人会话保持不变。
- 记录测试 ID 和运行时关联证据，脱敏后再保存。可识别的真实数据与原始捕获仅放本地忽略目录。
- 优先只读探测。需要写操作时，限定到新建测试项目/会话，使用无外部副作用的动作；审批验证使用无害测试命令或 mock。
- 不为探测修改全局配置、认证文件、桌面数据库、网络公开范围或现有会话权限。实际发现额外敏感步骤时先核实范围。

## 结论类别

- VERIFIED：实际观测并有可复查证据，仅对已测版本和条件成立。
- DOCUMENTED ONLY：文档有描述但未在当前运行时验证。
- UNSUPPORTED / INACCESSIBLE：注明明确证据、限制和替代路线。
- UNKNOWN：证据不足。不得据此声称无接口，也不得声称已支持。

已验证限定范围内的真实发送、状态与命令审批子能力。完整客户端适配仍受实测报告中的版本、常驻上下文、恢复和安全部署门槛约束。
