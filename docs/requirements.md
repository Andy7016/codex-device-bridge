# 需求与验收边界

状态：需求基线；2026-10-28。原会话适配、恢复层和 Android v0.1 已部分验证，各项范围以[结果报告](results/2026-10-28-android-v01.md)为准；尚未完成全部产品验收。

## 使用场景

用户通过 Android 手机操作指定 Windows 电脑上当前桌面应用内的 ChatGPT 与 Codex 会话。现有官方移动连接经常失败；ToDesk 在相同设备之间较稳定，且使用代理时仍可工作。

该观察说明存在可用通信路径，尚不足以定位官方连接失败原因。首版优化结构化会话连接，不复制通用远程桌面功能，不依赖 ToDesk 私有协议。

## 功能验收

| ID | 能力 | 验收边界 |
| --- | --- | --- |
| R01 | 配对指定设备 | 短时一次性配对、电脑确认、设备身份可核对、可撤销 |
| R02 | 项目与会话浏览 | 保留桌面实际项目归属，分别识别本地和云端类型；不以 cwd 分组冒充完整桌面项目 |
| R03 | 历史 | 分页读取原会话；长历史、工具输出、附件和状态正确关联 |
| R04 | 对话与活动任务 | 向原会话发送、接收流式输出、补充指令、停止；保持运行环境和上下文 |
| R05 | 新建 | 指定设备、项目、类型和可用设置，返回真实会话 ID，桌面可见性需要验证 |
| R06 | 模型与推理强度 | 根据实际可用能力呈现；显示有效值和生效轮次；不假定修改正在运行的任务 |
| R07 | 审批 | 显示真实动作及范围；允许或拒绝；过期和已处理审批不能再次授权 |
| R08 | 权限设置 | 分开表示审批策略、沙箱和网络能力；电脑端上限始终生效 |
| R09 | 文件 | 区分上传副本、引用电脑文件、项目资料和覆盖；提供清晰目的地及成果下载 |
| R10 | 恢复与通知 | 断线补齐、重复请求去重、后台提醒、重启恢复，不把网络状态误作任务状态 |
| R11 | 运维 | 设备撤销、有效权限查看、脱敏诊断，故障能定位到连接链路 |

## 初始范围

- 第一验证对象为一台 Android 手机和一台 Windows 电脑；协议身份保留多设备扩展空间。
- 同时考虑已有 Codex 会话与已有桌面 ChatGPT 会话，分别给出证据和缺口。
- 当前不包含完整 ChatGPT 云端账号历史同步、通用屏幕控制、公开托管服务或计费系统。
- 不提前选择框架、加密实现或中继供应商。自用原型走通后，再评估发布、分发与适用授权。

## 数据权威与操作边界

电脑运行时是任务状态的权威来源。手机缓存允许过期，但必须可识别；请求提交、电脑接收、任务开始、任务完成分别表示。撤销设备阻止后续访问，无法收回已交付的数据；正在运行的任务是否停止需按独立策略处理。
