# 全文展开与异步提问记录验证范围

仅在合成夹具与项目自有回环TLS中测试新message只读RPC。测试内容包括中文/emoji/引号/反斜杠/换行逐字节还原、预览只保留前缀但完整内容可继续读取、单片回复有界、游标目标/用途/期限校验、正文同ID编辑中止拼接，以及主策略和设备撤销后拒绝片段读取。

新API只接受已授权会话别名与不透明游标，不接受原始线程ID、路径、方法或任意偏移。不得借这次修复打开手机发送/作答/审批权限，不发送真实回答，不恢复或修改原会话。原会话仅允许只读核对字段存在、计数和大小，不输出/保存正文。

Android只做主包、测试包与Lint构建。本轮不重启模拟器；上一轮因内存阈值保护取消的设备测试不能计为通过。编译保持1.5GiB、单次进程及最多两工，Windows打包在Android构建退出后顺序执行。结束核对自建测试/构建进程退出；正常运行的正式Companion与按需读取服务保留。
