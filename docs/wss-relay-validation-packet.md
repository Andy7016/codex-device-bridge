# WebSocket 中继隔离验证范围

日期：2026-10-30。用户授权实现 Cloudflare 方案及其可迁移承载，提供 Render 操作方法。公网部署与真实设备网络测试另行记录。

## 对象与限制

- 目标仅为仓库自己的协议核心、127.0.0.1 上临时启动的 Node/Render 适配器、Wrangler/workerd 本地实例，以及项目自有 Android API35 模拟器。
- 所有身份、证书、票据、会话和文本均为每次新生成的合成材料，保存在被忽略的 test-results/ 或 .local/ 下，不接入原桌面运行时。
- 单个测试服务最多8条有效连接；单轮总测试升级请求不超过300次，二进制测试流量不超过8MiB；畸形大帧不超过32KiB。
- Node协议测试单轮最长30秒；集成实验每实例最多180秒；Android实验最多15分钟，到期停止。只监听回环，不改VPN、代理、DNS或防火墙。
- 新开模拟器须使用项目的专用AVD。只关闭本轮启动的服务/模拟器；不清理既有用户数据或其他实验材料。新生成实验身份在结束时撤销，进程停止并检查回收。

## 预期结果

1. 无登记、错误角色、过期/伪造/错受众票据在配对之前失败，不能创建任意主机DO。
2. 两端hello完成后只转发有序二进制，不存储载荷；通道ID不跨重连复用。
3. 超长消息、慢接收端、连接/字节/绝对时间上限触发关闭，旧绑定不匹配新通道。
4. 同一协议在Node适配器和本地workerd中均能转发真实的内层TLS。
5. 原手机密钥完成AndroidKeystore mTLS；错误身份在写请求前失败。
6. 合成submit回复丢失后保留原操作ID，通过status/reconcile核对；运行时发送计数为1。
7. 撤销立即阻止电脑端操作/结果释放；云端接入撤销由下一条已认证host hello同步，旧快照不能恢复已撤销项。
8. 构建包不含实验资产、私钥、凭据、个人对话或日志。部署构建dry-run不等于部署成功，模拟休眠不等于真实workerd休眠验证。
