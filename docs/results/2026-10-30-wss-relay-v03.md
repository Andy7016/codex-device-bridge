# 可迁移托管WSS中继 v0.3.0

日期：2026-10-30。基线为9933c03。用户授权先实现Cloudflare后端，保持同技术可移植，并提供Render操作方法。范围限连接层、配对路由资料、恢复与部署文件；未向原Codex或ChatGPT会话发送消息，未修改其授权或运行时入口。

## 实现

- Cloudflare Workers + SQLite Durable Objects与Render Node Web Service共享同一鉴权/转发核心，保持相同WSS路径、subprotocol、两端hello及有界二进制承载。
- 云端只登记电脑公钥与256位注册凭据的SHA256；电脑使用原DPAPI凭据。手机用电脑签名的固定ES256/JWT路由票据，验证issuer、audience、subject、时间、签名以及签名公钥SPKI身份。
- 首次配对使用最长约12分钟的路由票据，配对邀请本身仍为120秒并要求本机核对授权。设备路由票据最长30天，在原mTLS认证响应内续期。路由凭据只允许接入，不替代手机证书与电脑上的具体权限。
- 新档案v3与二维码v2支持WSS，原v1/v2档案及原TLS中继保留。给已配对设备签发的120秒连接更新二维码覆盖新路由并由原电脑签名；Android用已固定的电脑公钥检查，只替换路由而不更换手机密钥、档案ID、授权或outbox。
- Android使用Java-WebSocket1.6.0的帧与累计消息限制、独立SSLEngine、逻辑主机名验证和精确电脑证书固定。应用取消与网络改变中止旧承载，取消后不换路重试；开始尝试写业务请求后仍按unknown保留结果并只读核对。
- 服务端限制每主机最多8条物理连接（包含尚在关闭的连接）、2条活跃电脑通道、4条活跃手机通道，120次新连接/分钟，最多登记16台电脑。hello5秒、等待/活动通道各45秒绝对期限、每消息16KiB、每通道合计1MiB；Node积压有64KiB阈值。云端不持久化载荷。
- 撤销立即约束电脑端后续操作和结果释放；云端撤销由下一条已认证host hello同步，旧快照不能清空撤销。云端同步存在网络与等待槽延迟，不作为端点撤销的唯一机制。
- Companion增加WSS地址设置、中继登记导出和原设备连接更新二维码。新增私有仓库Render部署Blueprint及两平台部署说明。

## 联调修正

- 实验中同步WebSocket客户端与TLS1.3组合发生间歇升级超时；隔离对照中TLS1.2路径通过。改为单事件循环管理外层TLS I/O后，默认TLS策略下两种后端整组通过。该结果支持选用异步承载，不宣称已确认某个上游缺陷；没有降低产品TLS最低版本或关闭验证。
- 回调不在应用锁内执行库关闭；逐帧入队与取消共门控。代理选择使用完整目标路径，HTTP显式代理当前失败关闭。
- SSLEngine保留unwrap在CLOSED状态同时产生的末尾明文，先排空再报告EOF。
- 已逻辑关闭但尚未物理移除的WebSocket仍计入总连接上限，避免关闭握手拖延绕过资源预算。
- Android前台ERROR状态可重新启动轮询，默认网络变化触发旧通道中止；保留只读核对与不重发边界。
