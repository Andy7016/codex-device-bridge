2026-10-28。用户已授权继续接入独立 Codex 入口、验证断线/未知结果核对/撤销，以及既有两条专用会话的固定合成消息测试。

## 目标和限额

- 自动测试仅连接项目自建 loopback TLS 服务、合成运行时和 stdio 夹具，不操作真实桌面会话。
- 一次真实贯通测试只向已授权的 `Device Bridge Codex 测试` 发一条固定 `DEVICE_BRIDGE_HELLO_V1` 消息，要求固定 ACK，不使用工具或操作文件。
- 服务绑定 `127.0.0.1` 随机端口，临时证书只用于本机测试，三个测试主机进程依次运行，每个有 150 秒看门狗。Node 子进程调用限时 20 秒。
- 在原运行时已观察到精确消息 ID 后，故意结束本项目桥接测试进程，保留 journal 的 dispatching 状态；不结束或重启桌面应用及原模型运行时。
- 重启后先查 unknown，再从原会话快照按持久消息 ID 和原文核对；不重发。重复提交同一操作只查已有状态。
- 从过期游标恢复日志快照；撤销测试设备后验证已有 TLS 连接、新请求、读取、核对、排队发送和重启后的访问均被阻止。
- 排队操作仅写入本项目测试日志，撤销后必须为 cancelled，真实运行时尝试标记总数必须为 1。

## 保护与停止条件

真实测试使用 `.local/integrated-live-run.claim.json` 的独占持久声明。已存在声明时禁止自动重跑、换新 ID 或删除声明；先检查记录与原历史。私有配置、证书、测试 SQLite 和证据保留在声明指向的任务目录，不入库、不批量清理。

遇到目标身份/原文不匹配、协议变化、失去正向证据或超时，保留 unknown 并停止写入。撤销只阻止尚未交接的操作和后续结果交付，不声称撤回已经交接的任务。

ChatGPT 调查只读检查官方文档、已安装程序和既有测试会话的 owner discovery。不得编造 caller context、复用失效任务 ID、导出认证令牌、直连私有云端写接口、注入桌面进程或扩大本地 IPC 权限。
