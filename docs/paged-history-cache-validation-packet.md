# 0.3.7分页/缓存验证范围

合成测试只使用项目自有临时配置、回环TLS/假路由、合成内容，以及精确AVD路径`.local/android-avd/DeviceBridge_API35.avd`的emulator-5582。不能对公网Worker、真实手机或原会话进行攻击测试；不创建/恢复/发送原会话，不扩大授权，不改全局配置、认证或桌面数据库。

覆盖长轮次拆页无遗漏、8个工具空轮次仍可继续、同ID正文/状态变化、跨目标/过期游标拒绝、条件读取仍核对撤销、子进程关闭与固定只读方法拒绝写入。原Node owner/审批/不重发用例继续运行。真实现有会话只在已授权清单前三条读取一页，只输出计数、大小与类型，结束关闭自建读取服务。

Android合成缓存测试用随机连接ID，验证加密落盘、身份/会话/游标隔离、损坏记录作为缓存缺失、覆盖恢复和清除。每个缓存上限64页/2MiB；主APK不得包含测试assets，签名与已交付版一致。忘记连接不能清除或重发原outbox。

资源安排：构建与模拟器顺序运行；项目Gradle内存1.5GiB、最多两工、编译器进程内运行，不保留后台daemon。测试AVD只用单核、请求1GiB RAM、无窗口，不加载快照；启动110秒/测试90秒上限，系统可用物理内存低于1GiB即关闭该自有设备。停止后核对无qemu、Java或测试读取进程遗留；用户运行中的正式Companion除正常升级外不强制终止。
