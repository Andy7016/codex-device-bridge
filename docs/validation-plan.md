# 连接、恢复与攻击测试计划

状态：计划，未执行；2026-10-28。此文档不构成测试通过或漏洞发现报告。

## 授权与环境

用户已同意按整体方案推进，并要求连接与恢复验证在必要时加入攻击测试。当前测试边界为本项目拥有的隔离测试客户端、电脑代理与中继、测试身份及合成数据。

不攻击 OpenAI、ToDesk 或其他第三方生产服务，不对真实个人会话注入恶意内容，不使用生产账户令牌作攻击材料。真实设备网络切换测试与敌手流量测试分开运行。

每次执行前记录精确目标、环境归属、测试数据、工具版本、流量/并发上限、超时、停止条件和清理步骤。首批敌手测试只绑定 loopback 或隔离私有网络，不向公网暴露监听器。资源耗尽用例先对 mock 和进程配额运行。

## 结果与证据格式

每个用例记录：caseId、commit、环境/版本、步骤、预期、实测、通过/失败/未执行、脱敏证据、剩余限制。原始捕获放忽略目录 test-results/；入库报告只含经检查的合成/脱敏材料。

## 连接和恢复

| ID | 场景 | 预期 |
| --- | --- | --- |
| C01 | Wi-Fi 与蜂窝切换；代理开关 | 重连后身份保持，当前任务状态正确，消息无静默丢失 |
| C02 | 手机锁屏、Doze、后台回收和重新启动 | 通知按可用机制到达；打开后补齐；缓存过期有明确状态 |
| C03 | 电脑断网/恢复、Bridge 重启、中继重启 | 重新认证并对齐状态，不把离线误报为任务失败或完成 |
| C04 | 提交已到达但确认丢失；重复发送 | 查询同一操作；不重复启动；上游不确定时标记未知并核对 |
| C05 | 事件丢失、重复、乱序和保留期溢出 | 去重、检测缺口；无法重放则从权威快照恢复 |
| C06 | 手机和桌面同时回答同一审批 | 只接受一次有效决策，其他界面显示已处理 |
| C07 | 修改设置时另一端正在发消息 | 有效配置与轮次可核对；冲突显式处理 |
| C08 | 配对撤销、密钥轮换与恢复旧备份 | 撤销设备不能重接；待发操作不能越过新授权状态 |
| C09 | 附件中断、重传、磁盘不足 | 校验完整性，防重复覆盖，清理仅限本次拥有的临时产物 |
| C10 | 主机睡眠、桌面退出、模型服务不可达 | 分段诊断准确，恢复后不误重放高影响操作 |

## 攻击用例

| ID | 模拟攻击 | 预期安全属性 |
| --- | --- | --- |
| A01 | 未配对客户端、伪造设备身份、错误密钥 | 在业务读取或执行前拒绝；无敏感错误泄露 |
| A02 | 配对码重放、过期和受限猜测 | 单次有效、到期失效、有速率限制，不泄露设备秘密 |
| A03 | 恶意中继修改/注入密文、替换端点身份 | 完整性或身份验证失败，禁止降级明文和跳过证书校验 |
| A04 | 中继重放历史有效请求，重新连接后重放 | 防重放和业务幂等同时成立；断线不重置授权历史 |
| A05 | 替换项目/会话/轮次 ID 跨范围访问 | 主机逐次检查归属和权限，不能读取或操作其他范围 |
| A06 | 过期审批、审批内容替换、重复审批 | 决策绑定具体操作及状态；版本变化后旧授权失效 |
| A07 | 降权/撤销与已排队请求并发 | 最终执行前核对有效授权；审计可解释边界 |
| A08 | 伪造客户端角色、权限/模型参数或原始 RPC | 主机执行授权上限和方法白名单，拒绝隐藏接口绕过 |
| A09 | 路径穿越、绝对路径、junction/符号链接逃逸 | 文件访问和覆盖均限制到授权真实路径；考虑检查/使用竞态 |
| A10 | 正文伪造系统审批、恶意 Markdown/链接 | 内容不能获得原生授权能力；渲染和链接策略有效 |
| A11 | 畸形帧、超大输入、受限并发及队列压力 | 有大小、内存、速率和队列限制；拒绝后服务可恢复 |
| A12 | 合成秘密流经日志、通知、崩溃报告和缓存 | 中继无正文密钥；各输出只包含允许数据，秘密不外泄 |
| A13 | 伪造恢复游标、删除/回滚幂等记录 | 不跨设备取数据，不因回滚重新授权；缺证据时安全停止/核对 |
| A14 | APK/代理更新包被修改或降级 | 在设计的版本与签名策略下拒绝；保留可控恢复途径 |

## 门槛与停止条件

- 首先对 mock 执行协议和攻击测试，再接桌面测试运行时。测试不要求真实命令造成破坏。
- 出现越权读取、重复执行、未经授权的审批、明文凭据/正文泄露或隔离逃逸时立即停止对应通路，保留脱敏证据并修复。
- 安全属性至少包括认证、授权、保密、完整性、防重放、恢复正确性和受限负载可用性；有效值与上游未知窗口必须有明确设计。
- 未解决的高影响失败阻止扩大到真实会话。任何验收结论注明版本、条件、覆盖范围；不把计划、mock 通过或短时连通当作完整验证。
