# Android v0.1 验证包

基于用户开发 Android APP 的授权，沿用专用 Codex 测试会话和固定合成消息范围。先编译、静态检查和隔离测试，再作一次真实 Android→mTLS→恢复主机→桌面原运行时验证。

- 使用本项目新建的无界面 API 35 AVD，仅复用只读系统镜像；不读写其他 AVD 用户数据，不操作实体手机。
- 服务仅监听 127.0.0.1，模拟器通过 10.0.2.2 访问；使用新生成的证书身份、精确服务器证书固定和主机授权，不改防火墙或 SDK 全局配置。
- APK 不内置证书、账户凭据或真实会话 ID。测试证书只进忽略的 generated AndroidTest assets，不进入主 APK；配置和证据在 .local。
- AndroidTest 只向已授权 Codex 测试会话发送一次固定 HELLO/ACK 文本，不使用工具。主机故意丢失该操作确认，手机保存 unknown，重建 repository 后核对原操作，重复调用同一 ID 不重发。
- 本地独占声明 .local/android-app-live.claim.json 绑定测试目录和操作 ID。已有声明后只沿用原记录，不删除日志、换身份或换 ID 重做未知发送。
- 断言 APK 中的密钥保存和 interrupted sending→unknown；检查未配对界面禁用发送、未知操作只提供核对。之后只读查看原任务终态，并验证撤销和 TLS 错误拒绝。
- 所有真实写入仅限该测试消息，模拟器安装包仅在本项目实例；不调用未支持的 ChatGPT、模型设置、审批或文件接口。普通文本模式实现为本地显式配置，真实测试保持关闭。
- 测试主机有 15 分钟看门狗，完成后停止；保留私有证据，不批量清理原始记录。
