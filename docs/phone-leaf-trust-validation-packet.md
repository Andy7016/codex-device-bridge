# 同名手机证书信任验证范围

目标仅为项目自有隔离回环中继、Host和合成客户端；不攻击公网Worker、OpenAI、用户真实手机或原会话。每个用例使用临时配置、P-256合成密钥和单一合成会话。

顺序完成两部相同证书主体名称但不同密钥的设备配对，各读取一次合成目录；加载第三部未登记的同名证书并预期TLS/请求拒绝；撤销第一部并预期拒绝；确认第二部仍可读取。一次只发一个请求，合计不超过12条RPC、最多两个Host等待槽，单连接有原有超时。关闭Host及中继并检查工作线程退出；合成目录仅保留在忽略的test-results下。

改动只将已明确配对的证书作为叶信任锚，TLS签名/有效期验证及应用层精确证书指纹授权保留。匿名和未知证书没有会话权限。原有撤销、恢复、不重发、只读权限用例继续验证。真实手机随后只重试现有读取连接，不重新配对，不更换身份或放宽证书验证。
