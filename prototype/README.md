# 本地连接与恢复实验原型

本目录原 synthetic 路径提供 mock adapter、SQLite 状态日志与 loopback 双向 TLS，用于隔离验证恢复和授权。同日新增[真实 Codex 恢复主机](DESKTOP.md)，复用日志和 TLS 接入原运行时，已完成真实崩溃/撤销测试。两者均为本地实验，没有可部署中继或 Android 客户端。

以下组件和限制描述原 synthetic 路径；真实主机另见上述说明。真实主机拒绝网络 approve，不使用 synthetic 审批冒充真实决定。

## 运行

在仓库根目录执行，要求 Python 3.11+、可用的 OpenSSL CLI 和本机 loopback socket：

```powershell
python -m unittest discover -s tests -v
```

不需要 OpenAI API key、真实账户或网络下载。测试临时生成自签测试证书，存放在忽略的 `test-results/loopback-<random>/`；测试结束检查该精确目录并删除本次直接创建的文件。不会递归清理其他目录，不会写入用户配置。异常中断留下的目录保留供检查，禁止对整个 test-results 或工作区进行无差别清理。

## 组件

- `journal.py`：设备/会话授权、操作 ID 去重、持久分发标记、未知结果、事件序列和快照、带动作摘要和有效期的审批。
- `lease.py`：本地 OS 文件锁，防止第二写入实例对仍在使用的日志进行启动恢复。
- `loopback.py`：只允许 loopback 绑定，要求客户端证书，按证书指纹识别设备；仅开放 submit/status/sync/approve 四个实验方法。
- `tests/test_recovery_lab.py`：真实本机 TLS socket、故障注入、服务重建、实际子进程崩溃和有界攻击用例。

## 恢复契约

1. 提交操作时固定 `(device, operationId)` 和请求摘要。相同操作返回已有状态，内容改变则拒绝。
2. 调用 mock adapter 前持久记录 dispatching。调用后未能记录结果时，状态为 unknown，不自动重试。
3. 确认包丢失后，重新连接并查询同一操作；不能通过生成新 ID 解决不确定结果。
4. 事件按会话排序；保留范围内增量补齐，过期游标触发快照，超前或伪造游标拒绝。
5. 每次操作按当前设备授权校验。撤销阻止后续访问和待分发操作；不能撤回已执行动作或已交付数据。
6. 审批在同一事务中校验动作、期限、会话范围和状态；并发决策只产生一个结果事件。

## 明确限制

- 这是 Python 测试实验，不锁定未来 Android/Windows 产品技术栈。
- 没有公网中继、穿透、长连接流式事件、Android 后台通知或代理/蜂窝实测。双向 TLS 只保护实验中的这一跳，未实现经过不可信中继的端到端加密。
- 证书由测试夹具预置，不包含真实配对、证书更新、吊销列表、安装包签名或发布流程。
- TLS 证书校验与指纹匹配之后，仍需设备/会话授权；任何正文都不能选择调用身份或角色。
- 无真实命令执行、文件上传、OpenAI 调用或桌面审批授权；mock 只回显合成文本。
- 当前每连接一个请求，8 KiB 帧上限、4 个工作线程和 2 秒连接超时。没有大规模日志分页、流量配额或完整资源压力验证。
- 日志只用于合成数据；未实现生产级静态数据加密、数据保留和备份回滚防护。需要真实运行时幂等契约才能进一步处理外部副作用。
- 文件锁依赖本地文件系统；生产部署的账户隔离、多进程/多机与崩溃完整性需要独立验证。
